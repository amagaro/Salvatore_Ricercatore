# 💡 Concetto: Model Predictive Control (MPC)

## Definizione
Sistema di controllo avanzato in cui un algoritmo utilizza un modello termofisico dell'edificio insieme a dati previsionali meteorologici (Intelligenza Artificiale / Reti Neurali) per anticipare e pre-azionare le reazioni della facciata adattiva, anziché semplicemente reagire linearmente al superamento di una determinata soglia (controllo reattivo).
